# OpenRTE - Automated Statutory School Infrastructure Auditor

An automated civic intelligence engine that identifies Right to Education (RTE) Act compliance deficits in rural public schools using government UDISE+ data, and automatically generates legally grounded grievance dossiers citing Section 19 of the RTE Act, 2009.

## Features
- Automated detection of statutory infrastructure violations (sanitation, drinking water, electrification).
- LLM-powered legal grievance and RTI drafting citing Section 19 and Supreme Court precedents.
- Interactive dashboard powered by Streamlit and Google Gemini.

## Setup
1. Clone repository: `git clone https://github.com/<your-username>/open-rte-audit.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run dashboard: `streamlit run dashboard.py`
